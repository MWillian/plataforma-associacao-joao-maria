# Casos de Teste — Autenticação

| ID | Cenário | Passos | Resultado esperado | Prioridade |
----------------------------------------------------------------------------------------------
| AUT-001 | Login válido | Informar credenciais válidas e acessar | Usuário acessa o sistema | Alta |
| AUT-002 | E-mail inválido | Informar e-mail em formato inválido | Sistema apresenta validação | Média |
| AUT-003 | Senha incorreta | Informar senha incorreta | Sistema impede o acesso | Alta |
| AUT-004 | Campos vazios | Tentar acessar sem preencher os campos | Sistema sinaliza os campos obrigatórios | Alta |
| AUT-005 | Logout | Acessar o sistema e encerrar a sessão | Usuário é desconectado | Alta |
